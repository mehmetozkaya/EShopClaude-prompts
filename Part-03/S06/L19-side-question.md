# Lecture 19 - A Side Question with /btw

The one prompt in this lecture. Everything else typed here is a command (`/`, `/help`, `?`, `!`, `Ctrl+G`, `/config`), and commands live in the lecture's On-Screen Action blocks, not in this library.

**Where:** the `claude` prompt, in the middle of any task.

**What it does:** Claude answers on the side. The answer never enters the conversation history, so the main context does not grow.

```text
/btw which port does the web frontend use in launchSettings.json?
```
